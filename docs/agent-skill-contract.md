# Agent Skill Contract

本文档定义 `cncmachining-web` skill 的能力边界、输入输出和约束，是项目内 agent 使用该 skill 的契约。

## 1. Skill 标识

| 项目 | 内容 |
| --- | --- |
| Skill 名称 | `cncmachining-web` |
| Skill 路径 | `.codex/skills/cncmachining-web/SKILL.md` |
| 触发范围 | Lancoprecision 官网的需求、架构、CMS、询盘、SEO 和部署相关任务 |
| 不触发范围 | 与该项目无关的通用网页、其他公司官网或通用 CMS 问题 |

## 2. 目标

Skill 应帮助 agent 在项目约束内完成：

- 需求澄清和文档维护。
- Astro、Tailwind 页面和组件实现。
- Strapi 内容模型和内容 API 集成。
- 询盘表单、文件上传和服务端处理。
- 响应式、无障碍、SEO 和性能检查。

## 3. 输入

- 用户自然语言任务。
- 当前需求文档和契约。
- Strapi 内容类型与示例数据。
- 待审查或待修改的源码。

## 4. 输出

- 与需求基线和契约一致的实现。
- 同步更新后的需求和契约文档。
- 可验证的构建、类型和验收结果。
- 明确的未完成项或外部依赖。

## 5. 边界

Skill 必须执行：

- 遵守 `AGENTS.md` 的不变约束。
- 服务端校验询盘和附件。
- 保持内容由 CMS 驱动。
- 保持移动端可用性。

Skill 不得执行：

- 扩大一期范围。
- 提交密钥或客户隐私数据。
- 用库存图冒充真实工厂素材。
- 在契约未更新时直接实现字段或接口变更。

## 6. 失败条件

出现以下情况时，agent 应停止自动推进并报告：

- 缺少品牌素材、认证文件或关键业务数据。
- 域名、邮箱、WhatsApp 或第三方账号未确认。
- 外部部署、邮件或存储服务不可用。
- 需求冲突导致无法同时满足性能、隐私和可用性。

## 7. 契约同步

以下变更必须同步本文档、`AGENTS.md` 和相应契约：

- CMS 字段新增、重命名、删除或关系变化。
- 询盘请求或响应结构变化。
- 路由或本地化路径变化。
- 第三方服务替换。
