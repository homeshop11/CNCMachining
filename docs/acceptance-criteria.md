# Acceptance Criteria

本清单用于发布前验收，验收结果应记录通过、失败或不适用。

## 1. 导航与页面

- 所有一期路由可访问，无 404。
- 主导航在桌面和移动端可操作。
- 当前页面或当前产品线有可感知的导航状态。
- 页脚可从任意页面访问，包含地址、电话和隐私政策链接。

## 2. 首页

- 首屏包含价值主张、工厂实拍图、主要 CTA。
- 首屏在桌面和移动端留出下一区块可见空间。
- 5 个产品线入口均可点击并进入对应详情。
- 4 个核心卖点完整可见。
- 不自动播放音乐或视频。

## 3. 产品线页面

每个产品线页面：

- 显示名称、摘要和详细描述。
- 显示材料、规格、公差和表面处理。
- 显示应用行业或至少提供等价信息。
- 提供询盘表单和 WhatsApp 快捷入口。
- 产品图片和媒体均可正常加载，图片有 alt。

## 4. About Us

- 显示设备清单或工厂能力数据。
- 显示质量管控流程。
- 证书 PDF 可点击查看。
- 团队介绍真实且不包含误导性素材。

## 5. Contact

- Email、Phone、LinkedIn、WhatsApp 入口正确跳转。
- 表单字段标签清晰，错误提示可理解。
- Google Maps 嵌入在桌面和移动端可显示。

## 6. 询盘表单

- 必填字段缺失时阻止提交并提示。
- Email 格式错误时提示。
- 附件类型和大小不合规时提示。
- 成功提交后返回明确成功状态。
- 服务端收到邮件和备份记录。
- 重复提交不会导致明显混乱。

## 7. 响应式与视觉

- 360px 到 1440px 无横向滚动。
- 无文字重叠、无按钮截断、无控件溢出。
- 图片在移动端保持比例，不拉伸。
- 表单控件和按钮在 hover、focus、loading 状态无布局跳动。

## 8. 无障碍

- 图片有非空 alt，装饰图有空 alt。
- 表单控件有关联 label。
- 图标按钮有可访问名称。
- 键盘可完成主导航、表单填写和提交。
- 文本对比度满足 WCAG 2.2 AA。

## 9. SEO

- 每页 title 和 description 唯一。
- canonical、结构化数据和 Open Graph 基础信息存在。
- `sitemap.xml` 和 `robots.txt` 生成并可通过构建检查。

## 10. 性能与运维

- Core Web Vitals 达到需求文档目标。
- 构建命令通过，无阻塞错误。
- 环境变量未提交到仓库。
- 生产日志不包含密钥或完整客户数据。
